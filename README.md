## Mission 1: HTML Document Structure

### Concepts Learned

* **`<!DOCTYPE html>`** — tells the browser to use modern HTML standards mode.
* **`<html>`** — the root element of an HTML document.
* **`<head>`** — contains metadata and page information.
* **`<meta charset="UTF-8">`** — specifies character encoding.
* **`<meta name="viewport">`** — helps the page adapt to different screen sizes.
* **`<title>`** — sets the title displayed in the browser tab.
* **`<body>`** — contains the page's main content.

### Practical Work

* Created the basic HTML document structure in `index.html`.
* Added a page title, a main heading, and a paragraph.
* Opened the page in the browser using Live Server.
* Verified that the HTML content rendered correctly.

### Key Takeaway

An HTML document has a standard structure. The browser uses this structure to interpret the page and display its content.

## Mission 3: HTML Text Formatting

HTML provides several tags to format text and give it different meanings or appearances.

### 1. Basic Text Formatting Tags

| Tag        | Purpose                                       | Example                    |
| ---------- | --------------------------------------------- | -------------------------- |
| `<strong>` | Indicates important text                      | `<strong>Strong</strong>`  |
| `<em>`     | Adds emphasis to text                         | `<em>Emphasized</em>`      |
| `<i>`      | Represents text in an alternate voice or mood | `<i>Italic</i>`            |
| `<b>`      | Draws attention to text                       | `<b>Bold</b>`              |
| `<u>`      | Marks text with an underline                  | `<u>Underlined</u>`        |
| `<del>`    | Represents deleted text                       | `<del>Deleted</del>`       |
| `<big>`    | Displays larger text (obsolete in HTML5)      | `<big>Big</big>`           |
| `<small>`  | Represents smaller text                       | `<small>Small</small>`     |
| `<sub>`    | Displays subscript text                       | `<sub>2</sub>`             |
| `<sup>`    | Displays superscript text                     | `<sup>2</sup>`             |
| `<mark>`   | Highlights text                               | `<mark>Highlighted</mark>` |

### 2. Practical Examples

```html
<p>This is a normal text</p>
<p>This is a <strong>Strong</strong> text</p>
<p>This is an <em>Emphasized</em> text</p>
<p>This is an <i>Italic</i> text</p>
<p>This is a <b>Bold</b> text</p>
<p>This is a <u>Underlined</u> text</p>
<p>This is a <del>Deleted</del> text</p>
<p>This is a <big>Big</big> text</p>
<p>This is a <small>Small</small> text</p>
<p>This is a <sub>Subscript</sub> text</p>
<p>This is a <sup>Superscript</sup> text</p>
<p>This is a <mark>Highlighted</mark> text</p>
```

### 3. Special Notes

* `<strong>` and `<em>` communicate meaning, not just appearance.
* `<sub>` is useful for formulas such as H₂O.
* `<sup>` is useful for expressions such as x².
* `<mark>` highlights text.
* `<big>` is obsolete in HTML5. CSS should be used to control text size in modern webpages.

### Learning Outcome
