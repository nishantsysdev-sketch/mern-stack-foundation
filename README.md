## Mission 1: HTML Document Structure

### Concepts Learned

* **`<!DOCTYPE html>`** — tells the browser to use modern HTML standards mode.
* **`<html>`** — the root element of an HTML document.
* **`<head>`** — contains metadata and page information.
* **`<meta charset="UTF-8">`** — specifies character encoding.
* **`<meta name="viewport">`** — helps the page adapt to different screen sizes.
* **`<title>`** — sets the title displayed in the browser tab.
* **`<body>`** — contains the page's main content.

### Practical Work

* Created the basic HTML document structure in `index.html`.
* Added a page title, a main heading, and a paragraph.
* Opened the page in the browser using Live Server.
* Verified that the HTML content rendered correctly.

### Key Takeaway

An HTML document has a standard structure. The browser uses this structure to interpret the page and display its content.
